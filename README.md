# マネーコンパス（金融アフィリエイトサイト雛形）

保険の見直し・無料保険相談をテーマにした静的サイト。サーバー不要で、GitHub Pages / Cloudflare Pages / Netlify にそのまま置ける。

## 構成
- `pages/*.html` … 各ページの本文（1行目 `title:`、2行目 `desc:`）
- `build.py` … 共通ヘッダー・フッターを付けてルートに HTML を出力（`python3 build.py`）
- `js/data.js` … 掲載する無料保険相談サービス・アフィリエイトリンク・確認日
- `js/main.js` … サービス一覧・比較表の描画と必要保障額シミュレーター
- `css/style.css`

## 公開前にやること
1. ASP（A8.net、アクセストレード、afb、もしもなど）に登録し、無料保険相談（FP相談）案件と提携する。案件ごとの禁止事項を必ず読む
2. `js/data.js` に正しいサービス名と内容を公式サイトで確認して入れ、`affiliateUrl` と `checkedAt` を更新する
3. `pages/about.html` に運営者の実名・経歴・資格を入れる
4. 問い合わせフォームを用意する（Googleフォームでよい）
5. 独自ドメインを取り、Search Console に登録する
6. `python3 build.py` を実行してから公開する

## 法令・規約の要点
- **保険業法（最重要）**：保険募集人の登録なしに、特定の保険商品を比較・推奨して加入を勧めると「保険募集」に当たるおそれがある。このサイトは**相談サービスの紹介だけ**を扱い、個別の保険商品のランキングや「この保険がおすすめ」は書かない。
- **ステマ規制（景品表示法）**：広告であることがわかる表記が必須。全ページの上部に表記済み。
- **景品の訴求**：「相談するだけでプレゼント」型の案件は、景品の訴求方法がASPの規約で細かく制限されていることが多い。案件の指示どおりに書く。
- **成果の条件**：保険相談案件は「相談の完了」が成果条件で、冷やかしの申込みや重複は否認される。自分や知人による申込みは規約違反。
- **制度の数値**：高額療養費・遺族年金は制度改正が続いている。具体的な金額を書くなら一次情報（厚生労働省、日本年金機構）を確認し、出典を書く。

## 公開（GitHub Pages）
1. GitHub で空のリポジトリを作る（無料プランは Public が必要）
2. このフォルダを push する（`.github/workflows/deploy.yml` が `build.py` を実行して自動公開）
3. リポジトリの Settings → Pages → Source を「GitHub Actions」にする
4. `build.py` の `SITE_URL` を公開URLに書き換えて push
5. 未記入の箇所をすべて埋めたら `NOINDEX = False` にして push → Search Console にサイトマップを登録

`build.py` は実行時に未記入の箇所を一覧表示する。何も表示されなくなるまで `NOINDEX` を外さないこと。
